# Коммуналка Б

Изолированный каркас архитектуры Б для A/B-проверки против действующей
Коммуналки А.

На 2026-07-21 здесь намеренно нет бизнес-реализации: сначала Владимир
согласует минимальный граф, структуру БД и перечень интерфейсов. SQL-проект
лежит в `db/design/schema_v0.sql`, но в пустую БД не применён.

Целевой стек:

- FastAPI — небольшой сервер HTTP API;
- React — отдельный управляемый интерфейс;
- PostgreSQL — собственная БД проекта Б;
- системные службы Linux — запуск, расписания и журналы без отдельного
  оркестратора.

Целевой серверный путь: `/var/www/komunal-dom-b`.
Целевой адрес: `https://new.komunal-dom.ru` после добавления DNS и сертификата.
