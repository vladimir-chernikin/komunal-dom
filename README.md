# Kom_Dom_B — Коммуналка Б

Изолированный каркас архитектуры Б для A/B-проверки против действующей
Коммуналки А.

Проект полностью отделён от Коммуналки А. На 2026-07-22 поднят только
безопасный технический контур: проверка здоровья сервиса доступна, а
бизнес-API возвращает явный отказ до реализации и приёмки диалогового цикла.
SQL-проект лежит в `db/design/schema_v0.sql`, но в пустую БД пока не применён.

Целевой стек:

- FastAPI — небольшой сервер HTTP API;
- React — отдельный управляемый интерфейс;
- PostgreSQL — собственная БД проекта Б;
- системные службы Linux — запуск, расписания и журналы без отдельного
  оркестратора.

Локальный путь: `C:\codex\Kom_Dom_B`.
Серверный путь: `/var/www/Kom_Dom_B`.
Адрес: `https://aspect.komunal-dom.ru`.

Главный вход для нового окна Codex — `PROJECT.md`. Архитектура, схема БД,
инвентаризация API и порядок развёртывания находятся в `docs/`.
