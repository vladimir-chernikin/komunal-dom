# systemd

На текущем этапе работает одна прикладная служба `kom-dom-b-api.service`.
Telegram является HTTP-маршрутом этого процесса; отдельный пустой сервис не
создаётся.

`kom-dom-b-api.service` — единственная служба начального контура. Она слушает
только `127.0.0.1:8100`. Отдельный worker не создаётся, пока у проекта нет
реальной фоновой очереди. Бизнес-API отвечает безопасным 503 и не принимает
трафик Asterisk до реализации графа.
