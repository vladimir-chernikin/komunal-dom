## 4. Union vs Intersection - ПОДРОБНО ✓

**INTERSECTION** (пересечение) - НЕ ИСПОЛЬЗУЕТСЯ:
```
{25, 7} ∩ {25, 26} ∩ {25} = {25}
```

**UNION** (объединение) - ИСПОЛЬЗУЕТСЯ:
```
{25, 7} ∪ {25, 26} ∪ {25} = {25, 7, 26}
```

**ПРИОРИТЕТЫ (весовые коэффициенты):**
- Найден 3 сервисами → confidence × 1.8
- Найден 2 сервисами → confidence × 1.4
- Найден 1 сервисом → confidence × 1.0

**ПРИМЕР:**
- Service 25: confidence=0.95, 3 источника → 0.95 × 1.8 = 1.71 → 1.0
- Service 7: confidence=0.75, 1 источник → 0.75 × 1.0 = 0.75

**Результат:** [25 (1.0), 7 (0.75), 26 (0.6)]

## 5. "Используется UNION (не Intersection)" ✓

**Значение:** Код использует UNION (объединение), а не INTERSECTION (пересечение)

**Почему UNION лучше:**
- INTERSECTION может потерять кандидата если один сервис не нашел
- UNION сохраняет все найденные услуги
- Priority system позволяет ранжировать
