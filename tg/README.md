# Telegram

Telegram подключается к одному маршруту `POST /tg/webhook` основного FastAPI.
Маршрут проверяет закрытый заголовок Telegram и на текущем этапе честно
сообщает, что бизнес-агент ещё переносится. После реализации `ai` транспорт
будет только превращать обновление Telegram в общий входной контракт и
возвращать готовый ответ канала.
