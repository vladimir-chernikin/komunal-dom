```

├─ VectorSearchService - семантический поиск

└─ AI Orchestrator - генерация вопросов через YandexGPT
```

## Проблемный диалог
```
User: у меня течет
Bot: Где именно? В квартире или общедомовой?

User: в зале
Bot: Из какого именно места?

User: из трубы
Bot: Из какой трубы? (горячей или холодной)

User: отопление
Bot: Что именно случилось с трубой?

User: течет
Bot: Течет в вашей квартире или общедомовой системе?

User: я уже сказал
Bot: Уточните какая проблема?
```

**Проблемы:**
- Бот спрашивает "где?" при txtPrb="течет из трубы отопления в зале"
- Бот игнорирует established_filters с confidence > 0.8
- Бот не реагирует на раздражение
- Двойные вопросы через "или"
- txtPrb накапливается, но НЕ используется для фильтрации

## 3. Реальный пример

На шаге #8 диалога (пользователь: "отопление"):

**Входные данные:**
```
txtPrb: "у пользователя течет из трубы в зале"
established_filters:
  - location: Индивидуальное (95%)
  - category: Отопление (95%)
  - incident: Инцидент (90%)

candidates: 3 услуги
- ID:25 Прорыв труб в квартире (Водоснабжение)
- ID:31 Устранение течи из батареи отопления (Отопление)
- ID:33 Течь из трубы отопления в квартире (Отопление)
```

**Ожидаемый вопрос:**
```
"Опишите характер течи из трубы отопления в зале (капает, струей, постоянно)?"
```

**Почему лучше:**
- Учитывает txtPrb (знает про "течет" и "зал")
- Уточняет ДЕТАЛИ, а не основное
- Открытый вопрос
- Приближает к выбору услуги (ID:33)

## 4. План тестирования

**Тест 1:** txtPrb="течет из трубы отопления в зале" → вопрос НЕ "где?", НЕ "что именно?"

**Тест 2:** Пользователь "я уже сказал" → детектор frustrated=True → меняется стратегия

**Тест 3:** location=95% → вопрос НЕ "какая локация?"
