## 1. ПРИЧИНЫ ОШИБОК

### Ошибка 1: AttributeError: 'str' object has no attribute 'COOKIES'
- **Причина:** Кастомная фильтрация в `get_queryset` вызывала конфликт с jazzmin
- **Решение:** Убрана фильтрация по `show_all_closed`, оставлена только оптимизация select_related

### Ошибка 2: Некликабельные строки
- **Причина:** `list_display_links = None` убирало кликабельность
- **Решение:** Изменено на `list_display_links = ['work_order_no']`
